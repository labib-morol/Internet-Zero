## New controls this audit (Task 3)

1. `/readyz` returns **503** when unready (`routes/health.ts`) — orchestrators act on status; compose `r.ok` check now correct.
2. **Origin/CSRF gate** for cookie-authenticated mutations (`security.ts` `registerMutationOriginGuard`): cookie+missing/hostile Origin → 403; Bearer and cookie-less requests exempt; dev-localhost convenience only while the server itself is local. Note: hooks must `return reply.code(...).send(...)` to halt the lifecycle.
3. **Proxy-aware rate limiting**: `TRUST_PROXY=1` keys buckets on the RIGHTMOST X-Forwarded-For entry (proxy-added); client-supplied leftmost entries cannot forge buckets. Render blueprint sets TRUST_PROXY=1; direct exposures keep socket IP.
4. **Production origin hardening**: `NODE_ENV=production` requires an https:// PUBLIC_ORIGIN (`config.ts`).
5. **WS hardening**: hello deadline (default 10 s, test-injectable); session-scoped socket registry lets logout close live sockets.
6. **Pool resilience**: `pool.on("error")` — a terminated idle DB connection (DB restart, admin drop) is logged, not an unhandled exception that kills the process (found via the readyz test's DROP DATABASE).
7. **OAuth**: state cookie now Secure under https; outbound GitHub fetches have 10 s deadlines.
8. **Graceful shutdown**: SIGTERM/SIGINT drain has a 10 s force-exit deadline and exits non-zero on close failure.
9. Render blueprint: explicit `dockerfilePath: ./infra/Dockerfile`, `TRUST_PROXY=1`, `NODE_ENV=production`, documented single-replica constraint.
